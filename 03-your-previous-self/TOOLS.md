# Інструменти

| Завдання | Початковий шлях | Коли потрібна заміна |
| --- | --- | --- |
| Документи | Markdown і GitHub | PDF або DOCX як експорт для читання |
| Блокінг | Godot або Unreal після аудіотесту | Остаточного вибору немає |
| Геометрія і рендери | Наявний Blender | Для пререндерених шарів або моделей |
| Зображення | Згенеровані референси та ручна доробка | Готовність ассета перевіряється окремо |
| Звук | Audacity і нативний мікшер рушія | Окремий middleware за доведеної потреби |
| Музика | Авторські MIDI або аудіошари в доступній DAW | Композитор за наявності ресурсу |
| Монтаж | FFmpeg і наявний відеоредактор | Для трейлера та тестових записів |
| Реєстр ресурсів | ASSETS.csv | Перенесення у трекер після виробничого рішення |

Власні Unreal, Blender і наявні інструменти не трактуємо як дозвіл купувати нові плагіни. Початковий план не вимагає нових платних підписок. Claude/Codex допомагають із реалізацією, але результати перевіряємо у рушії.

## Перевірки перед вибором
Для кожного інструмента записати версію, підтримувану платформу, умови ліцензії і формат експорту. Додатковий SDK підключається тільки після того, як базова реалізація показала конкретний дефіцит.
