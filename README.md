## Як працюємо
- Редагуємо Markdown і реєстри безпосередньо в папці концепції.
- Зображення лежать поряд у `references/`; посилання відносні та працюють у GitHub.
- `exports/` містить читабельні видання документів. Markdown залишається робочим джерелом.
- Нове рішення записуємо в [DECISIONS](shared/DECISIONS.md), питання — в [OPEN_QUESTIONS](shared/OPEN_QUESTIONS.md).
- Не називаємо запропоновану деталь затвердженою. Позначення v0.1 означає початкову проектну редакцію.
- Після зміни механіки перевіряємо відповідні рівні, сценарій, звук і список ассетів.
