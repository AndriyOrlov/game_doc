## Як використовувати

1. Розкласти 1 зображення на силует, структурні маси, світлову ієрархію і path readability.
2. Зняти **принцип**, а не форму чужої будівлі чи персонажа.
3. Намалювати greybox еквівалент у нашому масштабі.
4. Записати очікувану реакцію гравця (бачу → розумію → дію → отримую наслідок).
5. Звірити з бойовими, аудіо- та UI-граничними умовами.
