## Концентрат напрямку
1. **NieR: Automata**: камера 3/4 → side → top-down без зміни базових правил керування, масштаби заводу.
2. **Hell's Paradise**: спокуслива краса саду, що маскує загрозу; нефрит, лотос, органічний захват архітектури. **Тенсенів буквально не повторюємо**.
3. **COCOON**: одна ясна інтерактивна мова, поступове комбінування правил, ігрові головоломки без текстових інструкцій.
4. **Control / BLAME!**: герой як мала фігура у величезному рукотворному просторі; читабельний силует і архітектура-маркер.
5. **GRIS / Scavengers Reign / Annihilation**: емоційна зміна світу, матеріальний зв'язок органіки й технології.
