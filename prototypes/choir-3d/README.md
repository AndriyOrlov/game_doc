# Хор порожніх машин — 3D вертикальний зріз 0.2

Браузерний 3D-прототип за GDD v0.1 (14.10.2026). Three.js r160, Web Audio, без зовнішніх ассетів: геометрія, текстури й звук генеруються в коді.

## Запуск

```bash
npm install
npm run build   # dist/index.html — усе вбудовано, працює офлайн без CDN
```

Відкрити `dist/index.html` у браузері з WebGL2. Звук стартує після натискання «Увійти до залу».

## Маршрут зрізу (ЛД)

| Зона | Координати, м | Що вчить | Як зроблено |
|---|---|---|---|
| Міст | z 34–48, ширина 4,6 | рух, удар | барикада з мертвих труб, 3 удари (комбо) |
| Передзал | z 20–34, 19×14 | слухати джерело | центральна перегородка, голос за нею, обхід до резонатора |
| Резонатор-головоломка | (−7,6; 22,4) | регістри | мотив високий–низький–середній, символи 1/2/3 смуги, помилка без штрафу |
| Поріг | z 15,6–20 | відбиття, ухилення | безпечні бурштинові кола (2 відбиття) і темна хвиля, checkpoint |
| Зал Трьох облич | r 15,5, активна зона r 12 | бій | 4 колони r 8,5 (ловлять лише промінь), ніші З/С, бос на півночі |

Камера: у залі — фіксована піднята перспектива, бос угорі, герой унизу, весь активний майданчик в одному кадрі. У передзалі стіни між камерою і героєм стають напівпрозорими.

## Числа з GDD, які використано без змін

- Рух 5 м/с; ухилення 0,24 с невразливості + 0,7 с відновлення; відбиття 0,12 с (допоміжне 0,22 с).
- 5 сегментів міцності, 1 с захисту після удару; резонанс 0–100, партія коштує 40.
- 96 BPM, 4/4: доля 0,625 с, такт 2,5 с. Патерн телеграфується за такт; фаза змінюється на межі такту.
- Фази: I 100–70 % лівий бас (три віяла зі стабільними проходами + позначені імпульси); II 70–35 % центральний голос (кільця, пауза, точний промінь); III 35–0 % правий дискант (спіраль, голоси чергуються, не більше двох разом).
- Резонатор у західній ніші приймає відбитий імпульс і глушить голос на 2 такти; перезаряд 6 тактів, з ніші не працює.

## Що додано поверх GDD (потребує рішення)

- Ударна хвиля голосника: якщо Носій стоїть ближче 3,4 м до відкритого голосника, той відповідає коротким кільцем на другій долі. Це правило проти безкінечного стояння біля цілі.
- Урон: удари 0,35 / 0,35 / 0,7 % за комбо, відбитий імпульс 3 %, партія біля голосника 4 %, приглушений голос ×2, пауза центрального голосу ×1,5.
- Після смерті — повернення до порогу поточної фази з повним здоров’ям.

## Шар левел-дизайну

`H` або перемикач у меню: колайдери (червоне), прохідні зони (жовте), активна зона r 12 (бірюзове), зони перекриття променя колонами, підписи вузлів, хітбокс героя 0,32 м.

## Структура

- `src/world.js` — геометрія зали, світло, колайдери
- `src/hero.js` — Носій, керування, комбо, ухилення, відбиття
- `src/hazards.js` — віяла, кільця, імпульси, голки, промінь, телеграфи
- `src/boss.js` — Три обличчя, фази, планування патернів по тактах
- `src/audio.js` — транспорт, голоси з формантами в просторі, реверб, сигнали
- `src/main.js` — потік гри, катсцени, головоломка, камера
