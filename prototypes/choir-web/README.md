# Хор порожніх машин · вебпрототип 0.1

Окремий короткий прототип за GDD v0.1. Не замінює заплановане демо на 60+ хвилин або кампанію на 15 годин. Рушій кінцевої гри ще не обрано.

Рух → резонатор Ⅰ Ⅲ Ⅱ → три фази боса → вибір зберегти чи стерти голос. Фіксована камера, п’ять сегментів міцності, відбиття, ухилення, резонанс, пауза й оригінальний синтезований звук. iPhone має сенсорний стік і кнопки, найкращий огляд у горизонтальній орієнтації.

ПК: WASD / стрілки, J / клік — удар зблизька, Space — ухилення, K — відбиття позначених імпульсів, Q — резонанс (40), E — взаємодія, Escape — пауза.

`dist/` є джерелом buildless статичного сайту. `npm test` перевіряє симуляцію без браузера. Фон — раніше створений оригінальний концепт акустичного залу; рухомі персонажі, загрози, колізія та ефекти виконуються кодом. Це не готова 3D-сцена. На фоні залишається намальована фігура біля входу; у прототипі це нерухомий андроїд.

Аудіо запускається лише після натискання «Увійти». Зберігається лише локальний підсумок останньої спроби. Резонатор і бій читаються без звуку. Арена не потребує зовнішніх CDN або API.

Обмеження: автоматичні перевірки логіки не замінюють перевірку браузера, звуку та керування на реальному iPhone. Браузерна QA у цьому середовищі недоступна.
